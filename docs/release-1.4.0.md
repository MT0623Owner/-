## 要望と対応

| 要望 | 対応・検証 |
| --- | --- |

| 演出 | 開示、得票集計、容疑者の通知、役職、残り時間、結果タイムライン。音・振動は初期OFF、スキップと動きを減らす設定に対応 |
| 容疑者の待機 | 公開ログの拡大、役割説明、残り時間。思考完了の対象外であることを表示 |
| 最終投票との混同 | 「容疑者による最終告発へ」に改名、0人では手動開始不可、勝敗条件を事前表示。最終週もまず通常投票 |

| いつでもルール確認 | ホーム・マスター・参加者のポップアップ。役職受領、占い師覚醒、容疑者化で自動表示 |

| デバッグ・整理 | 対象者の並び順、再ゲームの初期化、自動フェーズ進行の再検証をcoreへ集約。同じ同期で操作要素を作り直さない |

最終告発の同票は従来どおり人狼勝利です。再投票ルールは未採用のため追加していません。

## 自動検証

- `npm run check`：4ファイルの構文チェック成功。
- `npm test`：既存coreシナリオ、およびNode回帰・同期11件成功。
- `npm run test:browser`：Chromium 28件、WebKit 28件、計56件成功。モバイル画面とデスクトップ画面のマスター・参加者を検証。
- ブラウザ回帰はFirebase境界を差し替え、同期中の入力・カーソル・ボタン保持、ルール、QRの復号、思考完了、タイマー、告発、演出と秘密情報の表示範囲を検証。
- `tests/live-release.cjs`：実Firebaseに4つの独立した匿名クライアントで専用部屋を作成。占い師なし1戦、同じ部屋で再ゲームし占い師あり3週・容疑者2人・最終告発まで検証。作成した検証部屋だけを削除。既存のユーザーの部屋は操作しない。

実通信テストの実行（PowerShell、公開サイトにも同じテストを使用）：

```powershell
$env:CWW_LIVE_TEST = '1'
$env:CWW_TEST_URL = 'https://mt0623owner.github.io/-/'
$env:CWW_CAPTURE_DIR = 'C:\任意の検証画像出力先'
node tests/live-release.cjs
```

## 検証の限界

WebKitによるiPhone相当の画面検証は、実機Safariでのキーボード・ピンチ操作・物理的な音量や振動の確認を代替しません。占い師の勝率バランスは人間の複数回の対戦で調整します。実通信テストは配役を読んで分岐を確実に通す統合テストであり、AIの公平な対戦や推理力の検証ではありません。

Geminiの有効な個人APIキーによる外部生成は今回検証していません。実通信テストのお題生成はローカル方式です。

現在は信頼できる参加者同士の対面プレイ向けです。役職・伏せワードを含む部屋データが各端末に同期し、Firestoreの権限も認証済みユーザーを前提としています。改ざんや開発者ツールによる秘密閲覧を防ぐサーバー側権限分離は、このリリースの対象外です。

更新時は全員がページを再読み込みし、新しい部屋で開始してください。古いタブと新しいタブの混在は避けてください。
