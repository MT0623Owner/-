# 1.7.0 対面プレイの同期・進行・お題

## 方針

通知停止を端末固有の問題と断定せず、表示中20秒ごとのサーバー読取で補完する。getDocFromServerを明示し、キャッシュを最新と誤認しない。1回15秒上限、重複読取防止、退出・再接続・新しい通知を受けた後の遅い応答を捨てる。同一状態は描画しない。追加読取は最大180回/時/表示端末。自動書込再送・未確定書込の二重実行は行わない。

マスターは確認付きでゲームを中止して同じ部屋へ戻せる。参加者・設定を保持し、役職・投票・ログを消す。週追加は上限10、最終告発開始前のみ。期待する元の週数を検証して重複要求を無視する。投票結果確認中の次の進行も再計算するが、人数条件による最終告発や確定した勝敗は変更しない。

ローカルは34種類・234制約、選択式。日本料理・パン・果物・野菜・魚介類を追加。「答えやすい／標準／混ぜる」は知識レベルとは別設定で、各カテゴリに両難度を用意。AIには難度の指示を渡すが意味・バランスの自動保証ではない。

## 検証範囲

Node: 候補の両難度、権限、週数上限、重複追加、投票結果待ちからの延長、人数による最終告発、リセット後の秘密情報消去、AIの難度プロンプト。
ブラウザ: 通知を止めた状態からの自動反映と未送信入力の保持、失敗表示と再試行、同じ部屋でのリセット・日本料理の選択、最終週結果の演出内からの延長。

実物iPhone/iPadのネットワーク停止原因・利用者の実機での復帰時間・追加候補の対戦バランスは未検証。全員再読み込みして1.7.0で遊ぶ。

ローカル検証: 構文・core・Node27件成功。ブラウザ既存96件と追加の投票結果延長2件成功（試験初稿の3週目スキップ投票を同票の通常投票へ修正）。実Firebaseの独立4クライアントで占い師なし1戦・再戦・占い師あり3週と最終告発まで成功、ブラウザ例外なし。専用テスト部屋のみ削除。
