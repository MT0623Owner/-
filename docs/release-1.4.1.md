# 1.4.1 対戦後の見やすさ調整

2026-10-15、75HLでの対戦後の本人フィードバックに対応。ワード一覧は本人が選んだ「1人1行、その人のワードを横に並べる」で実装する。

## 演出を読む時間

- ワードは約5.1秒表示し、投票結果は集計完了後4.5秒残す。役職・ワードのめくりもゆっくりにし、結果カードは850ms間隔で順番に開く。
- 短い間隔で複数のワードが公開されたら順番に表示。スキップは表示中と待機中の演出をまとめて閉じる。
- 投票開始時は残りのワード演出を閉じて比較を優先する。新しい投票結果は古いワードより優先する。タイマーや入力は停止せず、再接続時に過去の演出を再生しない。
- 音・振動は初期OFF、動きを減らす設定とスキップを維持。

## 比較とルール

- 話し合い・通常投票・最終告発で公開ログを1人1行にする。左から古い順、空欄はダッシュ、最新は青緑。週の位置は全員で揃え、画面上の「○週目」の繰り返しは省く。読み上げ向けラベルには週を残す。
- 比較表を投票ボタンの直前に置き、本人のカードを折りたたむ。マスターの招待・部屋情報は比較表より下に置く。同期でカードの開閉や投票先の要素を作り直さない。
- 4人・3週の代表的なワードは390×844の画面内で比較。人数が多い場合も1人1行を維持し、内側の縦スクロールを廃止。週数が増えて幅が足りないときは、表の中を横にスクロールする。長い名前・ワードは省略せず折り返す。
- 結果のワードも1人1行とし、端末内だけの手動色分けを維持。
- 青緑（ワード）、黄（容疑者・結果・禁止事項）、紫（操作・ルール）をアクセントにする。ラベルと太字も併用し、色だけで意味を伝えない。
- ルールの冒頭に役職ごとの「すること」「禁止」を表示し、詳細は折りたたむ。役職・容疑者の自動案内、本人以外の秘密を表示しない仕組みを維持。
