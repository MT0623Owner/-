# 1.5.0 公開演出の全員確認

公開ワードと投票結果に共有の確認待ちフェーズを追加。容疑者と観戦マスターを含む開始時の全員を待つ。未確認者がいる場合、マスターだけが解除可能。

確認は既存のFirestoreトランザクションを使う。イベントIDは再戦でも引き継ぐ連番とし、古い確認・重複確認を無視する。次の週、占い師の覚醒、勝敗確定、話し合い時計の開始は確認完了後に行う。クライアント間の描画時刻は一致を保証せず、共有状態上の進行を止める。

演出はモーダルで背面操作を止め、Escape・動きを減らす設定・非表示タブでも自動確認しない。再入室時は確認状況を復元する。役職説明は個人用の従来動作を維持する。

招待情報を固定の「招待」ボタンから開くダイアログへ移動。人数が充足した際に古い最低人数警告を消し、新しい操作開始時も古いエラーを消す。

## 検証

- 構文検査、既存coreテスト、Nodeテスト14件成功。
- Chromium / WebKitのブラウザテスト70件成功。その後、確認待ちの再表示・動きを減らす設定を加えた対象8件も成功。
- 独立した匿名Firebaseクライアント4つで、占い師なしの勝利、再戦、占い師の2週目覚醒、3週・容疑者・最終告発まで成功。各公開演出で最後の確認前に共有状態が進まないことを確認。作成したテスト部屋のみ削除。
- これは自動統合テスト。実物のiPhoneでの通信遅延や全機種の描画一致を保証するものではない。

旧版クライアントは新しい確認フェーズを扱えないため、全員再読み込み後に新しい部屋で開始する。
