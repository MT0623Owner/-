# 演出強化 1.4.0（公開前）

2026-10-15、Knowledgeの `handoff-20261015-wordwolf-presentation-effects-maa-to-cdx` をcdxとして受領。6系統の実装依頼を、最新の1.3.2（`cd1fab7`）に適用しました。引き継ぎに記載された1.3.0は旧時点の情報です。占い師の秘密ルールとルールポップアップは維持します。

## 実装範囲

| 系統 | 実装 |
| --- | --- |
| ワード開示 | 短い溜めとめくり、新ワードの強調、前週ワードの小さな表示、任意の効果音・振動 |
| 投票 | 投票履歴から1票ずつ集計、容疑者スポットライト・枠付き表示、同票／スキップの「該当者なし」。終了後も得票数を表示 |
| 役職 | 自分のカードと説明ポップアップのフリップ、占い師覚醒の光、人狼カードの赤色と短い揺れ。役職専用の音や振動は出さない |
| 緊張感 | 既存タイマーの残り10秒から色と脈動、週ごとの背景色、画面端の容疑者人数、保存中の送信表示 |
| リザルト | 終了後に役職カードを順番に開示、人狼の制約をカードに掲載、実際に行った週のタイムライン、公開ワードの色分け |
| 待機・容疑者 | 公開ログを拡大、推理を続けられる案内、容疑者本人の最終告発画面だけ暗い配色 |

## 調整した点

- 任意の自然言語の制約を機械判定しません。結果画面でワードを押し「未判定→制約に合う→外れる」を切り替え、タイムラインと公開ログに反映します。端末内だけの振り返り用で、同期・得点・勝敗判定には使いません。
- 現行の伏せ入力にはカウントダウンがありません。ゲームルールを変えないため新設せず、既存の思考・話し合いタイマーだけを強調します。
- 音・振動は独立した初期OFF設定。音はユーザー操作からAudioContextを準備し、未対応・ブロック時は進行を続けます。ブラウザ再読み込み後の再生も最初の操作が必要です。
- 新規参加／再接続時に過去の開示・投票をまとめて再生しません。同じ同期内容で役職・開示・投票演出を繰り返しません。
- 演出は非モーダルで、次の入力・投票をロックしません。「演出をスキップ」で即時完了。役職説明は「閉じる」で終了します。OSの `prefers-reduced-motion` を尊重します。

## 実装境界

`presentation.js` は画面だけを扱います。`app.js` から、公開ログ、確定した投票履歴、容疑者ID、自分に表示された役職だけを渡します。部屋全体・他人の役職・未公開ワード・未確定投票は渡しません。結果カードにはRESULTフェーズに限って公開済みの正体と制約を渡します。

`game-core.js`、`room-sync.js`、Firestoreルール・スキーマ・書込処理は変更していません。既存セレクターも維持しています。公開ログ・役職カード・投票ボタンは、同じ内容の同期で再生成しないようにしています。
